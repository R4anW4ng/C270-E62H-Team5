# Split-the-Bill Group Ordering System

A web-based collaborative group ordering app that allows users to order food from different stalls together, split the bill automatically, and track expenses.

## Team
- Member 1 - Room Creator & Session Host
- Member 2 - Multi-Stall Cart Merger
- Member 3 - Automated Bill Splitter
- Alden - Vendor Fulfillment Dashboard
- Member 5 - Live Status Group Board
- Member 6 - Social Expense Tracker

## Tech Stack
- Node.js
- Express
- EJS
- MySQL
- Docker

## How to Run

### Prerequisites
- Node.js installed
- MySQL installed
- Docker installed

### Setup
1. Clone the repo
   git clone https://github.com/R4anW4ng/C270-E62H-Team5.git

2. Navigate into the project
   cd C270-E62H-Team5

3. Install dependencies
   npm install

4. Set up the database
   Run the SQL file in db/schema.sql in your MySQL client

5. Start the app
   npm start

6. Open your browser at
   http://localhost:3000
